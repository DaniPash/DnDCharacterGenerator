# ⚔️ D&D Character Roulette

Генератор персонажей для DnD 5e с колесом рулетки и AI-предысторией.

## 🚀 Деплой в Bolt.new (3 шага)

### Вариант A — Импорт через GitHub (рекомендуется)
1. Создай репозиторий на [github.com](https://github.com) и загрузи эти файлы
2. Открой [bolt.new](https://bolt.new) → нажми **"Import from GitHub"**
3. Вставь ссылку на репозиторий → готово!

### Вариант B — Ручной импорт
1. Открой [bolt.new](https://bolt.new)
2. Создай новый проект: **"Vite + React"**
3. В файловом панели слева замени файлы на эти
4. Нажми **"Run"**

## 🔑 API ключ (для генерации предыстории)

1. Получи ключ на [console.anthropic.com](https://console.anthropic.com)
2. В Bolt.new найди кнопку **"Environment"** (замок 🔒 слева)
3. Добавь переменную: `VITE_ANTHROPIC_API_KEY` = `sk-ant-...`

Без ключа приложение работает — просто без AI-генерации.

## 🎲 Как это работает

- **Колесо рулетки** крутится для каждого шага: раса → класс → предыстория → мировоззрение
- **Броски кубиков** (4d6, отбрасывается наименьший) для характеристик
- **Claude AI** генерирует имя, предысторию и промпт для изображения
- **Копирование промпта** для Midjourney, DALL-E или Stable Diffusion

## 🛠 Стек

- React 18 + Vite
- Чистый CSS (без UI-библиотек)
- Anthropic Claude API (claude-sonnet-4)
- Google Fonts: Cinzel + Raleway
